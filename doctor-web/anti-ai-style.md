# Anti AI Style Rules

本文件用于：

防止产品出现：

“AI 自动生成 UI 感”。

---

# 禁止风格

禁止：

* Vercel 风
* Linear 风
* Dribbble showcase 风
* AI startup 风
* 赛博科技感
* 未来感 UI
* 炫技设计

---

# 禁止元素

禁止：

* 毛玻璃
* 超大圆角
* 渐变背景
* 漂浮卡片
* 超大阴影
* 高饱和颜色
* 发光效果
* 彩虹色 tag

---

# 禁止布局问题

禁止：

* 超大留白
* 所有区域都有边框
* 所有元素都强调
* 页面持续高密度刺激

---

# 禁止信息问题

禁止：

* 所有数据同等重要
* 所有 metrics 一样强调
* tag 过多
* 所有区域同时抢视觉焦点

---

# 产品必须像

* 真实互联网医疗产品
* 长期运营系统
* 企业级 SaaS
* 医疗工作流平台

---

# 产品不能像

* UI showcase
* 学生设计稿
* AI 自动生成 demo
* 炫技 dashboard

---

# 最高原则

真正高级的产品：

不是：
“每个地方都精致”。

而是：

“信息节奏自然”。

真正高级的 UI：

不是：
“设计感强”。

而是：

“用户长期使用不疲劳”。
