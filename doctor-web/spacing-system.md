# Spacing System

## Core Philosophy

Spacing 的目标：

不是“大留白”。

而是：

建立：

* 信息节奏
* 页面呼吸感
* 扫读效率

避免：

* AI Dashboard 超大留白
* ERP 式拥挤布局

# Visual Density

本系统采用：

“中密度互联网医疗布局”。

目标：

* 一屏展示足够信息
* 不产生压迫感
* 不产生空洞感

避免：

* showcase 式超大留白
* ERP 式高压缩布局

---

# Silent Area Principle

页面必须保留：

“静区”。

静区：

指低视觉刺激区域。

作用：

用于缓冲用户视觉疲劳。

禁止：

所有区域同时高密度信息。
