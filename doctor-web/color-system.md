# Color System

## Core Philosophy

颜色系统目标：

* 医疗可信感
* 长时间阅读舒适
* 克制
* 低疲劳
* 数据清晰

避免：

* AI startup 薄荷绿
* 高饱和炫色
* 赛博科技感
* 过度渐变

# Risk Hierarchy

低风险：
低饱和绿色

中风险：
低饱和橙色

高风险：
克制红色

禁止：

* 荧光色
* 高纯度红绿
* 过亮提示色

# Tag Philosophy

Tag 不是装饰。

Tag 是：

“快速风险识别工具”。

禁止：

* 彩虹色 tag
* 大量 tag
* 所有 tag 同等强调

一个模块：

最多允许：
