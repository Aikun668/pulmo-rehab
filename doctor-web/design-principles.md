# Design Principles

## Product Positioning

本产品为：

现代互联网医疗患者康复管理平台。

目标用户：

* 医生
* 康复管理师
* 长期随访运营人员

产品核心：

不是炫技 UI。
不是 AI showcase。
不是传统政务后台。

而是：

“长期真实运营的互联网医疗产品”。

---

# Core Visual Philosophy

整体视觉必须：

* 克制
* 专业
* 温和
* 清晰
* 数据优先
* 工作流导向
* 长时间使用不疲劳

避免：

* AI startup 风
* Dribbble showcase 风
* 赛博科技感
* UI 炫技
* 未来感设计
* 过度视觉刺激

---

# Information First

UI 的核心目标：

不是“漂亮”。

而是：

* 快速扫描
* 风险识别
* 信息定位
* 长时间阅读舒适

信息优先级必须明确。

禁止：

* 所有元素同时强调
* 所有区域视觉权重相同
* 所有数据同等重要

---

# Enterprise + Internet Medical Balance

产品需要保持：

* 企业级可信感
* 互联网产品体验感

避免：

* 传统 ERP / OA 后台感
* 纯 AI SaaS Dashboard 感

---

# Visual Rhythm

页面必须存在：

* 强区域
* 弱区域
* 静区

避免：

* 页面持续高密度刺激
* 所有区域都在抢视觉焦点

真正高级的 UI：

依赖视觉节奏。
不是元素堆叠。

---

# Long-Term Product Mentality

整个系统必须像：

“已经运营 1~2 年的真实产品”。

而不是：

“学生作品”
“AI 自动生成页面”
“设计稿 showcase”

所有页面：

必须统一：

* spacing
* typography
* hierarchy
* interaction rhythm
* component language
