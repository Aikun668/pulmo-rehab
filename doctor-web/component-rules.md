# Component Rules

# Card Rules

Card 必须：

* 克制
* 清晰
* 信息优先

避免：

* 漂浮感
* 大阴影
* showcase 风

---

## Card Border

允许：

极浅边框。

禁止：

厚描边。
强边框。
所有区域都加框。

---

## Card Radius

Default:
12px

禁止：

超大圆角。

---

# Patient Card Rules

患者卡：

不是社交名片。

而是：

“风险扫描单元”。

---

## Information Priority

优先级：

1. 患者姓名
2. 风险等级
3. 核心指标
4. 康复状态
5. 描述信息

禁止：

所有元素视觉等级一致。

---

## Metrics

Metrics：

最多只允许：
1 个主指标高亮。

其他指标：

必须弱化。

避免：

所有 metrics 同时强调。

---

## Tags

最多：
3 个核心 tag。

Tag 必须：

* 小
* 克制
* 可扫读

禁止：

彩虹 tag。
大面积 tag。
tag 墙。

---

# Sidebar Rules

Sidebar：

必须：

* 稳定
* 克制
* 专业

避免：

* 赛博科技感
* 安防后台感
* 政务系统感

---

# Table Rules

Table：

优先：
浅分隔。

避免：
传统 ERP 网格线。

---

# Button Rules

Primary Button：

克制强调。

Secondary Button：

低干扰。

禁止：

渐变按钮。
发光按钮。
高饱和按钮。

---

# Hover Rules

Hover：

只允许：

轻微背景变化。

禁止：

大面积动画。
强 hover 效果。

---

# Shadow Rules

允许：

极浅层级阴影。

禁止：

浮层式重阴影。
Dribbble 风阴影。
