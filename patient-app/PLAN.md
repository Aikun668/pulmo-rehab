## 一、产品定义

**目标用户：** 重症肺炎恢复期居家患者

**核心场景：**
- 接收医生下发的训练处方，跟随呼吸陪练完成每日训练
- 训练前自评（呼吸困难 + 疲劳 + 心率 + 血氧）
- 查看训练进度、AI 康复小结、康复知识

### 3.1 首页 `home`

```
功能：进度环(Canvas) + 康复等级 + 连续天数 + 今日任务速览 + AI 预览 + 快速入口
```

- [x] 动态 Canvas 进度环（百分比弧线 + 文字）
- [x] 康复等级展示（1-5级，颜色区分）
- [x] 今日训练建议（按等级定制文字）
- [x] 今日任务速览（从处方缓存读取，每项名称 + 目标时长）
- [x] 连续打卡天数计算
- [x] AI 小结预览（截取42字）
- [x] 目标时长动态（从处方计算，不再写死20分钟）
- [x] 快捷入口：进度页、AI 小结页

**数据依赖：**
- `GET /api/patients/{id}/rehab-level` → 等级

**待优化：**

### 3.2 训练页 `check-in`（核心页面，已完成重构）

```
功能：呼吸陪练 + 处方智能加载 + 训练前自评 + 安全预警
```

- [x] **处方加载链：** active 医生处方 → 今日缓存 → AI 生成处方 → Level 默认方案
- [x] **呼吸计时器：** 吸气/屏气/呼气三阶段，按等级配置节拍（Level1:3-1-5, Level5:5-3-8）
- [x] **呼吸动画：** 圆圈缩放（吸气放大→屏气保持→呼气缩小）
- [x] **轮次控制：** 按等级配置轮次（Level1:5轮, Level5:10轮）
- [x] **自动填时：** 计时器完成后自动填充对应呼吸任务的时长
- [x] **训练前自评弹窗：** 呼吸困难(1-5) + 疲劳(1-10) + 心率(40-200) + 血氧(70-100%) + 备注
- [x] **安全预警：** 提交自评后检查预警接口，弹窗提示风险
- [x] **训练提交：** 校验所有任务完成 → 计算总时长 → 提交 `training-logs`
- [x] **今日状态：** 加载已有记录，标记已提交
- [x] **任务展开/折叠：** 查看每个动作的步骤和注意事项

**数据依赖：**
- `GET /api/patients/{id}/rehab-level` → 等级
- `GET /api/rehab-plans/active?patient_id=...` → 医生处方
- `POST /api/prescriptions/generate` → AI 处方（降级）
- `GET/POST /api/training-logs` → 今日记录
- `POST /api/assessments` → 提交自评
- `GET /api/warnings/latest-unresolved?patient_id=...` → 预警检查

**待优化：**
- [ ] 呼吸动画用 Canvas 取代 CSS scale（当前 scale 对性能友好但动画不够丝滑）
- [ ] 训练动作可增加图示（当前只有文字）
- [ ] 心率/血氧异常前置校验（在训练开始前拦截，而非仅评估后检查）

## 四、架构说明

### 4.1 数据流

```
app.js (globalData: token, patientId, ...)
  ↓
utils/auth.js (封装: login, checkLogin, request, getPatientId...)
  ↓
各页面 onShow() 调用 auth.request() 访问后端 API
  ↓
后端统一返回 { code, message, data }
```

### 4.2 处方加载链（训练页核心）

```
优先级1: GET /api/rehab-plans/active  → 医生已审核处方
优先级2: wx.getStorageSync(cacheKey)  → 今日缓存
优先级3: POST /api/prescriptions/generate → AI 生成
优先级4: LEVEL_DEFAULT_EXERCISES[level] → 前端内置降级
```

### 4.3 等级体系（五级）

| Level | 名称 | 颜色 | 呼吸节奏 | 推荐训练 |
|-------|------|------|----------|----------|
| 1 | 重度恢复 | `#ef4444` | 吸3-屏1-呼5, 5轮 | 腹式呼吸 + 被动活动 |
| 2 | 轻度活动受限 | `#f97316` | 吸4-屏2-呼6, 5轮 | 缩唇呼吸 + 床边坐立 |
| 3 | 中度恢复 | `#eab308` | 吸4-屏2-呼6, 8轮 | 深吸气 + 节奏控制 + 行走 |
| 4 | 恢复良好 | `#22c55e` | 吸5-屏3-呼7, 8轮 | 呼吸耐力 + 步行耐力 + 上肢 |
| 5 | 接近完全恢复 | `#3b82f6` | 吸5-屏3-呼8, 10轮 | 综合肺功能 + 有氧 + 力量 |
