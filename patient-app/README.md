# 患者端小程序

> 产品定位：面向重症肺炎恢复期患者，通过 AI 智能分析、呼吸训练指导、健康监测和动态处方调整，实现居家肺康复闭环管理的智能康复系统。
> 锚定文档：`../PLAN.md`

## 技术栈
- **框架**：微信小程序原生开发
- **渲染引擎**：WebView（已从 Skyline 回退，修复白屏问题）
- **语言**：JavaScript + WXML + WXSS
- **appid**：`wx7761ea799e603529`
- **npm 依赖**：无（纯原生项目）

## 页面结构

### 主页面（底部 tabBar）
| 页面 | 路径 | 职责 |
|------|------|------|
| 首页 | `pages/home/index` | 今日训练概览、进度圆环、连续打卡天数、AI 小结预览 |
| 训练 | `pages/check-in/index` | 呼吸陪练计时器 + 任务清单勾选 + 提交 |
| 康复 | `pages/rehab/index` | 统计横栏 + 训练方案入口 + 30天进度入口 + AI 小结入口 |

### 二级页面
| 页面 | 路径 | 职责 |
|------|------|------|
| 训练方案详情 | `pages/plan-detail/index` | 最新方案 + 历史方案 + 训练动作分步骤指导 |
| 30天进度 | `pages/progress/index` | 近30天训练趋势柱状图和统计摘要 |
| AI 小结 | `pages/ai-summary/index` | 最新 AI 康复周报 + 历史小结列表 |

## 组件
- `components/navigation-bar/`：自定义导航栏

## 已接后端接口
| 接口 | 方法 | 用途 |
|------|------|------|
| `/api/training-logs` | GET | 读取当天训练记录 |
| `/api/training-logs` | POST | 提交/更新训练记录 |
| `/api/training-logs/progress-30d` | GET | 读取近30天训练趋势 |
| `/api/rehab-plans` | GET | 读取训练方案列表 |
| `/api/ai-summaries/latest` | GET | 读取最新 AI 康复小结 |
| `/api/ai-summaries` | GET | 读取 AI 康复小结历史列表 |

所有接口已通过 `utils/auth.js` 统一鉴权，自动携带 Bearer token。

## 开发备注
- 首页进度圆环使用 Canvas 2D 新版 API 绘制
- 打卡页呼吸计时器：吸气4秒 → 屏气2秒 → 呼气6秒，5轮，圆圈缩放视觉引导
- 提交成功后自动跳转回首页刷新进度
- 所有页面 `onShow` 时重新拉取数据
